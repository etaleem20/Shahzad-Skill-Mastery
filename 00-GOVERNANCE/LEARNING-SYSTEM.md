# Learning System

## Standard Learning Cycle
1. Concept — چیز کیا ہے؟
2. Easy Explanation — آسان اردو میں سمجھ
3. Demo — استاد کی طرف سے عملی نمونہ
4. Practice — طالب علم خود کرے
5. Test — مختصر عملی یا نظری امتحان
6. Review — غلطیوں اور کمزوریوں کی تشخیص
7. Pass / Repeat — پاس تو اگلا Gate، ورنہ دوبارہ Practice
8. Portfolio Output — بہترین کام محفوظ

## Assessment Standard
- Concept Understanding: 25%
- Practical Execution: 40%
- Quality: 20%
- Explanation: 15%

Recommended Pass Mark: 80%

80% سے کم = Revision Required، ناکامی کا لیبل نہیں۔

## Teaching Rules
- ایک وقت میں ایک Concept
- Technical English کے ساتھ آسان اردو
- ضرورت سے زیادہ Tools نہ سکھائیں
- سیکھنے سے زیادہ Build کرنا اہم
- Learning تقریباً 30%، Building/Selling تقریباً 70%
- ہر سبق کے آخر میں: اہم بات، یاد رکھنے والی بات، Practical Task، Test یا Gate

## Documentation Rule
Repo میں صرف useful records رکھے جائیں:
- Concepts
- Final Prompts
- Important Exercises
- Tests
- Feedback
- Approved Outputs
- Portfolio Work
- Progress

عام Chat dumps، غیر ضروری drafts اور repetition محفوظ نہ کیے جائیں۔
